# 🚀 Task System - Backend API

API RESTful para gerenciamento de tarefas assíncronas com filas Redis e WebSocket.

## 📋 Sobre

Backend desenvolvido em Laravel 11 que gerencia tarefas assíncronas com suporte a filas prioritárias, retry automático, logs detalhados e WebSocket para atualizações em tempo real.

## 🛠️ Tecnologias

- **Laravel 11** - PHP Framework
- **PHP 8.4** - Linguagem
- **MySQL 8** - Banco de dados
- **Redis** - Fila e cache
- **Laravel Sanctum** - Autenticação via token
- **Laravel Reverb** - WebSocket

## 📦 Requisitos

- PHP 8.4+
- Composer
- MySQL 8+
- Redis


## 🚀 Como Executar

./start.sh
